# يزيد يعقوب الياس — الموقع الشخصي

موقع شخصي ثابت (HTML/CSS/JS) جاهز للنشر على GitHub Pages.

## طريقة النشر
1. أنشئ مستودعًا جديدًا باسم `USERNAME.github.io` (استبدل USERNAME باسم حسابك).
2. ارفع كل محتويات هذا المجلد (index.html ومجلد assets) إلى جذر المستودع.
3. من Settings ← Pages اختر الفرع `main` والمجلد `/ (root)` ثم Save.
4. بعد دقيقة يصبح الموقع على: `https://USERNAME.github.io`

## التعديل
- النصوص كلها في `index.html`.
- الألوان في أول ملف `assets/style.css` (المتغير `--red`).
- الصورة: `assets/yazid.webp` — والسيرة: `assets/Yazid-Elyas-CV.pdf`.
